# KPI UI Kit

`@kpi-ua/ui` is the shared UI for KPI web apps: shadcn-based components, the Tailwind v4 theme, the Exo 2 font, hooks, and better-auth helpers.

Source: [github.com/kpi-ua/ui-library](https://github.com/kpi-ua/ui-library)

## Install

The package is published to GitHub Packages. Authenticate with a GitHub token that has `read:packages`.

```sh
echo "@kpi-ua:registry=https://npm.pkg.github.com" >> .npmrc
pnpm add @kpi-ua/ui
```

## Setup

Global CSS (Tailwind v4):

```css
@import 'tailwindcss';
@import '@kpi-ua/ui/styles.css';
@import '@kpi-ua/ui/fonts.css'; /* skip in Next.js if you use exo2Font */
@source '../node_modules/@kpi-ua/ui/dist';
```

```tsx
import { Button } from '@kpi-ua/ui';

<Button>Зберегти</Button>;
```

### Next.js font

Add `transpilePackages: ['@kpi-ua/ui']` to `next.config`, then:

```tsx
import { exo2Font } from '@kpi-ua/ui/fonts/next';

<html className={exo2Font.variable}>
```

## Subpaths

| Import                   | Content                                           |
| ------------------------ | ------------------------------------------------- |
| `@kpi-ua/ui`, `/ui`      | Components                                        |
| `@kpi-ua/ui/hooks`       | Shared hooks                                      |
| `@kpi-ua/ui/lib`         | `cn` and helpers                                  |
| `@kpi-ua/ui/auth/server` | `createAuth` (better-auth, optional peer)         |
| `@kpi-ua/ui/auth/client` | `createAppAuthClient`                             |
| `@kpi-ua/ui/auth/next`   | Route handler, middleware, `getServerSession`     |
| `@kpi-ua/ui/fonts/next`  | `exo2Font` (needs `next`)                         |
| `@kpi-ua/ui/styles.css`  | Theme tokens                                      |
| `@kpi-ua/ui/fonts.css`   | Exo 2 `@font-face` (latin + cyrillic, 400 to 700) |

Use the sidebar to browse foundations (tokens, typography) and components. Every component page has live controls and a light/dark switch in the toolbar.
